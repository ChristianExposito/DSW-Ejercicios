# 💻 Desarrollo Entorno Servidor (DSW)

Este repositorio está destinado a organizar y almacenar todo el material de la asignatura de **Desarrollo Web en Entorno Servidor (2DAW)**, dividido limpiamente entre apuntes teóricos y ejercicios prácticos.

## 🚀 Guía Rápida de Git (Cheatsheet)

Para mantener el repositorio actualizado y sincronizado en tu ordenador, sigue estos pasos desde la terminal de IntelliJ IDEA:

### 1. Clonar por primera vez
Si necesitas descargar este proyecto en una carpeta nueva o en otro ordenador:
git clone <URL_DEL_REPOSITORIO> .

# 1. Selecciona y prepara todos los archivos modificados o nuevos
git add .

# 2. Guarda los cambios localmente con un mensaje descriptivo
git commit -m "Añadido nuevo ejercicio de prueba"

# 3. Sube los cambios definitivos a la nube (GitHub)
git push
